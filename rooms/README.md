# Sample rooms

Visitors without a photo can try one of these on the visualizer.

1. Drop room photos here (JPG, ~1600px wide, shot from standing height, floor clearly visible).
2. List them in `rooms.json`:

```json
[
  { "name": "Living room", "file": "living.jpg" },
  { "name": "Hotel lobby", "file": "lobby.jpg" }
]
```

The "No photo handy? Try one of ours" row appears automatically once the list isn't empty.
